- CAPSTONE PROJECT 1 - CodeStorm Challenge

- 🚀 Project Overview
This repository contains my completed solutions for the **CodeStorm Challenge Capstone Project**. The challenge evaluates fundamental and advanced programming concepts using Python through practical use cases and problem-solving exercises.

- 🛠️ Topics & Modules Covered
The project tackles 30 intricate coding problems spanning across:
1 Data Types, Indexing & Slicing: Working with strings, lists, tuples, sets, and dictionaries (e.g., Scoreboard Operator, Nutrition Bar Ingredient Chart, Book Sales Analysis).
2 Operators & Conditionals: Utilizing arithmetic, comparison, and logical operators for decision-making (e.g., Shipping Cost Calculator, Car Dealership Discounts).
3 Loops & Iterations: Implementing `for` and `while` loops, nested loops, and pattern/sequence generation (e.g., Dice Roll Statistics, Fibonacci Sequence Generator, Chess Tournament Match Schedule).
4 Custom Functions & Lambda Expressions: Writing reusable functions and leveraging `map`, `filter`, and `reduce`.
5 Object-Oriented Programming (OOPs): Creating classes, constructors, methods, and managing object states (e.g., Bank Account Management System, Basketball Score Tracker, Paint Brush Class).
6 Exception Handling: Robust error management using `try`, `except`, and `finally` blocks (e.g., Safe Calculator, Time Class Validation).
